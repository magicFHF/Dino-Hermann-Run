# Dino Hermann Run

Pixel-Jump-'n'-Run im Browser – spielbar unter **https://magicfhf.github.io/Dino-Hermann-Run/**

Jeder Push auf `main` veröffentlicht das Spiel automatisch über GitHub Pages (`.github/workflows/pages.yml`).

## Steuerung

| Taste | Aktion |
| --- | --- |
| Leertaste / Pfeil hoch | Springen (halten = höher) |
| P / ESC | Pause |
| S | Einstellungen |
